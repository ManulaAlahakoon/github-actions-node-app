<h1>CI Pipeline with GitHub Actions and Branch Protection</h1>
<h3>Technologies: GitHub Actions, GitHub, Node.js</h3>
<p>Built a CI pipeline using GitHub Actions to run tests, build the project, and validate code on pull requests across multiple Node.js versions (18.x, 20.x, 22.x)</p>
<p>Enforced branch protection rules requiring successful CI checks and review approval before merging to master</p>
